# MusicOps 图标

图标使用内置 imagegen 生成。`src/musicops/assets/musicops.png` 是原始透明 PNG，`musicops.ico` 由 `packaging/prepare_icon.py` 转为 Windows 多尺寸图标，用于窗口、任务栏、EXE 和安装包。

生成提示：

> Use case: logo-brand. Asset type: production Windows desktop application icon and GitHub project brand icon for MusicOps, a music-library organization app. Create one single centered icon, no text, no letters, no watermark, no presentation mockup. A beautifully crafted rounded-square midnight-navy glass tile with a bold luminous turquoise abstract music-wave / letter-M-like ribbon integrated with a small vinyl record arc, communicating ordered music and audio quality. Refined modern desktop-app identity, restrained depth, crisp silhouette, subtle cyan edge light, premium glass enamel, minimal details, recognisable at 32 pixels. Front-on orthographic composition, icon fills about 86% of a square canvas with consistent breathing room; true transparent background outside the rounded square; no ground plane and no cast shadow beyond the icon. Strong contrast, precise clean edges; avoid busy equalizer bars and generic musical-note clipart.
