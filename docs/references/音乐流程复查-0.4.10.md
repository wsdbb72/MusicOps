# 音乐流程复查（0.4.10）

参考现有项目的业务行为，保留 MusicOps 自身适配器与事务实现；不复制第三方项目源码，不把外部示例当成当前私人站点账户的实际验证结果。

| 领域 | 参考来源 | 本次处理 |
| --- | --- | --- |
| Gazelle 搜索身份 | [MoviePilot DicMusic 搜索回归](https://github.com/jxxghp/MoviePilot/blob/v3/tests/test_dicmusic_indexer.py) | 保留完整艺人、专辑、年份和种子 ID，补充发行类型、再发行年份、目录号、厂牌与介质。搜索展示信息与下载授权分开。 |
| FL 下载 | [MoviePilot Gazelle 账户解析](https://github.com/jxxghp/MoviePilot/blob/v3/app/modules/indexer/parser/gazelle.py) | 库存读取与下载消费分离。DicMusic、Orpheus 继续只接受当前登录页面可确认的 FL 链接，规范 `usetoken=1`，先验证下载器，再持久化消费意图并绑定种子哈希；不因看到免费标记就降为普通下载。缺少可靠链接或库存时进入核对。外部示例中的其他 URL 动作不能代替本机站点证据。 |
| 标签及合辑 | [MusicPilot 标签写入](https://github.com/lzcer/MusicPilot/blob/main/musicpilot/adapters/metadata/tag_writer.py) | 分清逐曲艺人和专辑艺人；合辑只改分组，逐曲原艺人不变。人工合辑撤去原专辑发行 ID，保留歌曲录音 ID，独立副本写入并读回核对。 |
| 录音与版本 | [MusicPilot 版本证据](https://github.com/lzcer/MusicPilot/blob/main/musicpilot/core/track_variants.py) | 普通、现场、混音、不插电、伴奏、小样和重制等分别处理；歌名别名不等于同一录音。特殊版并存时供用户选择一版或多版，同版只选一站，已有音源保留。 |
| 本地封面 | [MoviePilot 封面回归](https://github.com/jxxghp/MoviePilot/blob/v3/tests/test_music_cover_fallback.py) | 本地封面与专辑范围相关，支持艺人加专辑名的正面图片；同优先级不同内容不随意取第一张。保留封面来源和摘要，已有有效内嵌图片不被静默覆盖。 |
| 多源元数据 | [MusicPilot 多源资料](https://github.com/lzcer/MusicPilot/blob/main/musicpilot/adapters/metadata/multi_source.py) | 元数据、封面和歌词分别验证，不能因一个查询成功就假定其余资源存在。简体偏好仅自动写入有中文语言证据的名称，未知语言和日文保留原文。 |
| 音乐服务器 | [MusicPilot Navidrome](https://github.com/lzcer/MusicPilot/blob/main/musicpilot/adapters/media_servers/navidrome.py)、[MoviePilot 音乐刷新回归](https://github.com/jxxghp/MoviePilot/blob/v3/tests/test_mediaserver_music_refresh.py) | 音频提交成功后才请求扫描；请求成功与服务器实际识别成功分开报告。修正异常 JSON 的错误分类，避免已完成入库误显示成音频处理失败。Roon 依靠监听目录，旁置 LRC 与内嵌歌词也不直接等于界面显示成功。 |

Gazelle 发行类型编号依据 [上游表结构迁移](https://github.com/OPSnet/Gazelle/blob/master/misc/my-migrations/20181219213631_release_type.php) 与 [新增类型](https://github.com/OPSnet/Gazelle/blob/master/misc/my-migrations/20191229132006_release_type_v2.php)，未知编号保留原值，不猜测。跨站版本分组属于比较线索，不能表示已确认同一压盘或母带。
