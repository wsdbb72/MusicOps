修复 Linux 长路径、碟号与资料补全恢复问题。

- Linux 使用实际文件系统的路径与 UTF-8 文件名限制，保留根目录和软链接校验；新事务采用短暂存文件名，兼容旧事务恢复。
- 正确解析前导零曲号／碟号，保留局部库中已声明的总碟数。缺号只用已核实的曲目表填入，不把文件排序或单个文件冒充整张单曲发行。
- 封面增加专辑名兜底检索、共享登录态及逐曲时长核验；允许封面匹配中的英文冠词和客串标注差异，不将其用于确认不同录音或发行身份。
- 歌词临时网络错误采用延迟、有限重试，只刷新失败项；鉴权错误提示在设置中测试，不额外消耗 AI 请求。
- 已准备的曲序、封面和歌词任务可以用当前连接设置批量重试；目录改变或已有文件事务时阻止不安全重放。
- 增加 Windows／Linux 回归及真实 POSIX 长路径提交、回滚验证；macOS ARM 原生文件系统测试随完整发布工作流执行。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。

验收使用合成音频和临时档案，不下载真实音乐或消费 FL。在线资料缺失、来源不可用和真实损坏文件会保留核对状态；不会以跳过校验来提高成功数。
