修复 AI 核对重复排队、歌单本地音源核对和 Docker 内网服务连接，并加固网页端。

- 后台重启后，已排队但尚未运行的 AI 辅助核对只保留一个执行任务，不再重复调用 AI；已经完成的核对保留结果，不会重新执行。
- 歌单入库判断“音乐库已有”时，除标题、艺人、专辑和时长外，还核对录音版本（现场、混音、伴奏等）、指定的版本/发行标识、网易云曲目与专辑 ID、碟号和曲号，以及文件名与标签冲突；文件必须是扫描时记录的同一份未改动文件。版本不同的曲目会继续进入任务，不再被误判为已有。
- qBittorrent、Navidrome 和 Plex 在本机、局域网私有地址、`.local`/`.lan` 名称及 Docker 网络服务名（如 `http://qbittorrent:8080`）上可使用 HTTP；公网地址仍要求 HTTPS。
- 网页端在读取请求内容前先核对登录，未登录的慢速请求不能占满处理名额；浏览器中途关闭连接时不再产生重复错误日志。错误信息额外隐藏含 `api_key`、`secret`、`sid` 等参数的地址。
- Docker 健康检查不再受容器代理变量影响；Windows 程序文件版本号与应用版本一致。
- Mac 新增 Apple Silicon `.dmg` 磁盘映像，内含与 PKG、ZIP 相同的已验收应用，打开后拖入“应用程序”即可。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG、DMG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。

自动验收使用临时档案和合成资料，不下载真实音乐或消费 FL。
