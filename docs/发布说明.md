后台断开时自动重连，Docker 网页版显示当前版本。

- **不再显示“需要处理：[WinError 2] 系统找不到指定的文件”**：后台进程退出、崩溃或重启期间，桌面版连接后台时找不到通信管道，原先直接显示这条系统错误。现在识别为连接中断，自动重新启动并连接后台，期间显示“正在重新连接后台”；若此时点击了保存、订阅等操作，会提示连接恢复后重试。已有任务不受影响。
- **网页版显示当前版本**：Docker 原生 HTML WebUI 左侧栏底部显示正在运行的版本号（如 `MusicOps 0.4.28`），升级容器后可直接确认。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG、DMG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。
