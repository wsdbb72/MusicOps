歌词带时间轴写入，Roon、Navidrome 和 Plex 播放时歌词随进度自动切换。

- 同一份时间轴同时写入音频同名 `.lrc`（UTF-8 无 BOM，供 Plex、Navidrome 读取）和音频标签（FLAC/OGG `LYRICS`、M4A `©lyr`、MP3 `SYLT` 与 `USLT`，供 Roon、Navidrome 读取）。此前内嵌标签只保留无时间轴文字，Roon 无法同步滚动。
- 写入前统一为 `[mm:ss.xx]`：`[offset:]` 偏移折算进时间戳，一行多个时间戳展开为多行并按时间排序，去除逐字时间标记和网易云的 JSON 制作信息行；同一时刻的翻译行保持原顺序。网易云歌词不再因制作信息行被整体丢弃。
- 所有行停在同一时刻、不会随进度切换的伪同步歌词不会写入。
- 旧版本内嵌的同一份无时间轴歌词会在下一次资料补全时自动升级；用户自行写入的其他歌词与已锁定的歌词字段保持不变。已核对过的专辑会重新检查一次歌词。
- Roon 需在 设置 → 资料库 → 导入设置 中把“歌词”和“同步歌词”设为“优先使用文件”；Plex 添加歌词后对专辑执行“刷新元数据”。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG、DMG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。

自动验收使用临时档案和合成资料，不下载真实音乐或消费 FL。
