MusicOps 0.4.33 全量迁移到 Go：桌面壳、核心、打包与 Docker 入口全部改为 Go 实现，安装包与镜像内不再有 Python 运行时，不再解压 Python DLL。

- 桌面壳改为 Go 原生（Wails v2.17.1）：窗口直接渲染与 Docker 相同的 WebUI，同一套界面和操作；单实例、自启、反向代理（注入鉴权）。
- 凭证库改为 Go 实现的三平台 Vault（Windows DPAPI、macOS Keychain、Linux AES-GCM），与旧 Python 版格式互通，升级保留已有凭据。
- 自动更新改为 Go 实现：GitHub Releases 检查 + SHA-256 校验 + 交接安装。
- 配置迁移：旧 Python 配置可迁移到 Go 核心（只读读取，幂等，留有收据）。
- 命令行工具：version / status / jobs / job / control / stop / migrate，核心以 detached 方式运行，CLI 退出后继续工作。
- 执行器补齐：真实下载（qBittorrent：加种、归属校验、归档、入库）、转码（WAV→FLAC）、流媒体回退与歌单导入、目录接线（真实 MusicBrainz 查询）、媒体处理（NCM 解密、FLAC 标签、LRC、去重、艺人文件夹）。
- Docker 镜像入口改为 Go 二进制，无 Python 运行时；健康检查走 `musicops healthcheck`。
- 冒烟测试迁移到 Go 包（带桌面壳 23 项检查），发版门禁改为真实检查（包内容、Go 构建信息、版本、文件哈希、引擎、冒烟报告）。
- 许可证收集改为 Go 模块：`go list -m` 收集各模块许可证原文进包内 `licenses/`。

已知缺口（未完成，不当作已完成）：托盘图标装不上（Wails v2.17.1 无公开 API），`--minimized` 只能最小化到任务栏/Dock；桌面壳未在真实 Windows/macOS 硬件上跑过（以 CI 构建为准）；更新完整流程未在真机上走完；`core.log` 无轮换；任务级 retry 仍被核心拒绝；取消只在检查点被观察。真实 AI 调用、线上逐笔扣费格式、真实四站凭证与 qBittorrent 端到端、OpenCC 仍未接入。

注意：Docker 容器里，之前用 12–15 字符密码的用户升级后会看到明文启动错误而非静默复用（有意为之，否则核心会无明确原因退出）。本版 tag 的源码树仍包含旧 Python 源码（构建时仍需用到其中的图标与版本文件），删除放在同步到 main 时进行；安装包与镜像内已无 Python 运行时。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG/DMG/ZIP，以及 Linux amd64 原生 HTML WebUI 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。详见[性能与临时目录](性能与临时目录.md)。
