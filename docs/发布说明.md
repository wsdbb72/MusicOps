- **图标与 README**：新图标（渐变 + 唱片 + 波形，含 16–256 多尺寸 ICO），README 重写为安装、配置、工作流与接口的结构化文档。

MusicOps 0.4.35：令牌与去重两条线收尾，界面换成设计系统，歌词封面与网易云接入本体。

令牌与下载

- RED 与 DicMusic / Orpheus 共用同一套令牌账本：余额解析、观察提交、复核、迁移导入、获取判定都走同一个 `IsTokenSite`。
- 未对账的令牌请求 30 分钟后自动到期，不再永久占住整个站点；同资源仍然拒绝第二次 `usetoken`。
- 后台每 30 秒对账：余额下降判为已扣费，余额 5 分钟不变判为未扣费；只用已保存 Cookie，每站读余额至少间隔 60 秒。
- 账户余额在渲染页上按账号绑定（同页必须出现 `user.php?id=<账号>`）：DicMusic 的接口文档没有令牌字段，此前它的余额永远读不到。
- 令牌待核对的种子已保存时可以直接继续下载；下载只读本地种子，不会再发 `usetoken`。
- 下载中可暂停 / 恢复 / 重新校验 / 删除种子（保留文件）；取消落在执行器启动前也不会再卡死。

音乐库与刮削

- 批量刮削按专辑只查一次目录，可选同时取歌词与封面（一次最多 30 首）：先取后写，取不到就整首不动，封面写失败会恢复备份。
- 字段锁与去重抑制：按专辑目录保存，字段锁让自动写入跳过指定字段（勾选覆盖也不改），抑制让该专辑不参与重复扫描与合并。
- 合并重复时先用副本补齐保留文件的空字段并同步摘要，文件仍被 qBittorrent 做种则拒绝合并。
- 去重前的做种检查在 qBittorrent 不可达时保守拒绝，而不是当作安全。

歌词、封面与网易云

- 歌词与封面按 LrcApi 契约接入：地址、路径、鉴权取自「歌词与封面服务」设置，404 视为没有这一首并继续写标签，网络失败整单拒绝。
- 非回环只允许 HTTPS；带凭据时不跟随跳转，不带凭据最多 3 跳（公开服务的封面会 301 到 CDN）。
- 网易云歌单：详情只给少量曲目 + 全部 trackIds，其余按 100 一批补全，6000 首以内不再截断；分享链接带 `uct2` 参数也能解析。
- 内置网易云：保存账号 Cookie 后自行搜索并只取无损 FLAC，不依赖外部引擎；账号没有无损权限时如实报「只有有损音频」，不把 mp3 存成 FLAC。

界面

- 样式改为令牌化设计系统：颜色/字号/间距/圆角/阴影全部走变量，深色跟随系统；宽屏左侧栏、窄屏横向导航；补焦点环与「减少动效」。
- 修掉两处真实缺陷：卡片内所有按钮被一条通配规则压平成纯文本；种子控制按钮渲染了却从不显示。
- 待核对列表改为服务端筛选 + 游标分页，「加载更多」按游标追加，队列超过一页不再丢任务。

稳定性与接口

- 执行器 panic 的完整栈脱敏后写入 `panic.log`（1 MiB 轮换），任务行只保留首帧；`core.log` 在下次启动时轮换。
- `/v1/open/*` 是给外部软件的稳定面（解析歌单、检索、任务、核对、下载、种子控制、目录识别、入库、标签），配 OpenAPI 3.1 契约与 `X-API-Key`；独立入库不依赖工作流任务。
- 任务列表只对当前页出现的 root 做前缀查询，不再每次全量扫描专辑索引。

已知缺口（未完成，不当作已完成）

- 令牌 `in-flight` 上限仍为 1（文档写 2），提高需要真实未知扣费同时发生的验证。
- TIDAL / Apple Music / QQ 音乐仍依赖用户自行安装的 go-music-dl（AGPL，不随包分发）；Roon 需要用户的 Roon Core 才能验证。
- 桌面壳未在真实 Windows/macOS 硬件上跑过（以 CI 构建为准）；更新完整流程未在真机上走完。
- 迁移（旧 Python 配置/任务库）已完成备份与失败不阻断，但没有分段进度与半导入清理。
