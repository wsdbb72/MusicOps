新增订阅监控歌单，并大幅减少需要人工核对的任务。

- **订阅监控歌单**：在“歌单入库”页订阅歌单链接并设置检查间隔（1–168 小时，默认 6 小时）。后台定时重新读取，只把新增曲目按专辑自动入库；已在音乐库的跳过，歌单删除的曲目不会从音乐库移除。首次检查默认只记录现有曲目，可勾选“现有曲目也入库”。另一批歌单入库运行中或读取失败时稍后自动重试。桌面版与网页版均可立即检查、暂停、恢复或删除订阅。
- **封面元数据损坏不再判为音频损坏**：部分商店下载的 FLAC 内嵌封面图片本身正常，但图片类型为空、尺寸为 0，新版 FFmpeg 无法打开、旧版报错，导致整张专辑“音频校验未通过”。现在在整理副本上按图片实际内容修复这些字段，非图片数据的封面块会被移除，原文件直到入库前不会被改动。
- **本地资料补全不再因缺封面而整张待核对**：找不到可靠封面时，专辑艺人、碟号、歌词等其他修复照常完成，缺封面数量写入完成摘要；下载入库仍需明确确认才会无封面入库。
- **站点暂时不可用时自动重新检索**：限流、网络中断或站点暂时故障时，分别在 10 分钟、30 分钟、1 小时后自动重新检索，仍失败才进入核对；Cookie 失效等登录问题仍立即提示。
- **候选发行匹配更准确**：专辑名比较繁简体统一；“A & B”“A / B”“A feat. B”等合写艺人与分开列出的艺人视为相同，减少“找到了候选发行，需要核对艺人和版本”。不同艺人的同名专辑仍需核对。
- **空文件、损坏文件明确提示**：音频为空、截断或扩展名与内容不符时，任务进入核对并列出具体文件名，不再显示“处理未完成：FLACNoHeaderError”等内部错误名。
- **无标签的整轨镜像不再报“任务资料格式异常”**：单个 WAV/APE 加 CUE 且没有歌曲和专辑名时，转为人工识别。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG、DMG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。

自动验收使用临时档案和合成资料，不下载真实音乐或消费 FL。
