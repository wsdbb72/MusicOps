MusicOps 0.4.29 修复批量入库、队列恢复与大任务吞吐问题。

- 统一 `PolicyBlocked`，兼容原有 RuntimeError 捕获，恢复按真实原因跳过不安全目录移动的逻辑。
- 为事务 plan_id、事件任务/事务查询、专辑目录和名称候选建立持久索引；状态写入对 BUSY/LOCKED 有限重试，恢复写入再失败也不会杀死队列。
- 大文件校验、补全、发布和收尾可与独立轻任务同波运行，轻任务完成后继续补充；元数据最多使用 4 个槽，等待过久的补全任务提升优先级。
- 既有任务执行下一阶段时刷新识别、AI 及目录整理策略；下载前刷新音质策略，不改变原路径，不重放下载意图。
- qB 登录失败短期熔断，避免成批错误登录；修改凭据立即失效。401 与 403 提示区分凭据错误、可能封禁或代理限制。
- Windows 正式程序增加独立隐藏的后台监督和启动/退出/原生故障诊断；明确退出及更新交接会停止监督。安装器增加可选登录自启，默认关闭。
- 队列健康文件每 5 秒更新；Docker 健康检查覆盖线程存活和存储恢复状态。任务中心显示最近安全检查点。
- 桌面与网页均可选择不下载 DSD / SACD；过滤发生在令牌和下载动作之前，实际音源发现 DSD 时也不会开始整理转码。
- 入库前按艺人及归一化名称查询既有专辑，明确选择补入原目录或独立版本；已有重复副本继续通过去重合并页面核对，不按同名直接删除。
- 已入库文件被外部修改后，只有重新通过完整解码、录音身份和时长核对才记为完成并保留源文件提示；缺失、损坏或身份不符仍需核对。
- 公开网站访问规则拒绝后跳过重复请求；后台空闲时分批压缩归档 30 天前常规日志，文件及令牌审计保留。

详见[任务索引与故障恢复](任务索引与故障恢复.md)。进程监督和诊断改善可用性，不代表已证明机器级静默退出根因；不会以超时为由强制重放可能已提交的文件或下载操作。

提供 Windows 安装版与便携版、macOS Apple Silicon PKG、DMG 与 ZIP，以及 Linux amd64 原生 HTML WebUI Docker 镜像 `wsdbb72/muiscops:latest`。macOS 使用 ad-hoc 签名，尚无 Developer ID 公证。
