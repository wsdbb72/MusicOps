# MusicOps 使用说明

打开程序后按向导配置。所有连接都可以稍后设置；音乐库目录用于保存完成整理的文件，Roon 与 Navidrome 应监听同一个目录。下载和整理临时目录由程序管理，不要让音乐服务器监听整个磁盘。

## 第一次配置

1. 选择音乐库。使用 Roon 时，在 Roon → 设置 → 存储添加同一目录。
2. 在已登录的 PT 网站中使用 Cookie-Editor 导出 JSON。在向导中导入文件或粘贴 JSON，并勾选“参与检索”。没有账号的站点保持关闭。
3. 在 qBittorrent → 选项 → WebUI 开启 Web 用户界面。填完整地址、WebUI 用户名和密码。程序使用自己的分类、任务标签和下载目录，不改全局下载偏好。FL 预算是每批最多消耗的令牌数量；填 0 时只使用已经免费的资源。
4. 网易云回退可以不填 API。需要账户权限时可以使用自己已配置权限的网易云 API 服务，或选择客户端下载目录，程序通过标签或 NCM 元数据匹配曲目。API 使用 /song/url 的 JSON 格式；只有完整可用音源会被下载。FFmpeg 与 ffprobe 分别选择对应 exe。
5. 歌词鉴权填服务提供的完整 Authorization 原文，不自行添加 Bearer 前缀。Discogs Token 在 Discogs 开发者设置中生成。可选 AI 填 API 地址、模型及 API Key，用于解释待核对项目。
6. Navidrome 可跳过；需要时填写服务地址、有扫描权限的账号和密码，并确认服务器音乐目录与所选库一致。

已保存的秘密值不会重新显示。留空保留；地址改变时旧域名的凭据不会自动带到新服务。普通设置不保存明文秘密。

## 歌单入库

粘贴网易云歌单链接或 ID，点击“解析歌单”。勾选所需曲目并点击“开始入库”。表格包含全部可见曲目，不截断为前 1000 首。

上游清单不完整时保留警告，只处理用户明确选中的可见曲目。资料缺失先识别或核对，不会猜测替代曲目。现有库中身份和时长匹配的曲目跳过，余下曲目按专辑建立任务。

已配置站点没有资源时才回退网易云。登录、限流或网络错误不会伪装成“没有资源”。无法完整下载的曲目保留说明。已有客户端下载文件会复制到任务来源目录，原 NCM 与做种文件不修改。

## 补全与升级

“检查并自动补全”保留已有资料，补缺失标签和同步歌词，并统一完整多碟专辑的总碟数。资料不明确或缺少可靠封面时，在任务中心选中项目点击“核对 / 重试选中任务”。可以打开资料网站、逐曲确认标签、选择专辑封面，或明确跳过确实不存在的资源。

“检查并自动升级”只尝试有明确质量提升线索的候选。下载后检查实际格式、位深、采样率、声道、全部曲目及完整时长。无损压缩码率不用于判断升级；不同声道或不同录音不会自动替换。没有同一发行 ID 时，需要用户核对发行版本。新版通过完整验证并成功入库，才将旧版音源与相关歌词移出监听目录。

## 任务与恢复

任务中心支持分页、暂停、继续、取消，以及待核对事项。关闭窗口后后台继续；再次打开使用同一个 profile。暂停和取消在安全阶段生效，不停止做种，也不自动回滚已经完成的发布。

FL 请求超时保留未知状态，不能盲重试。qBittorrent 新增和启动必须先核对归属；已有非 MusicOps 任务不会被接管。中断后的文件事务保留日志与恢复副本，核对后处理，不能通过忽略校验强行发布。

恢复副本位于 profile 的 backup、quarantine，以及同卷整理工作区。它们在音乐库监听范围外。确认任务无误前保留；清理副本会减少可恢复的历史。

入库完成后 Roon 自动监听发现文件；启用 Navidrome 时会请求扫描。若客户端未显示，先核对监听目录、扫描状态与多碟标签。任务完成不等于已经在客户端逐曲播放验收。
