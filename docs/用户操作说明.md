# 用户操作说明

启动应用后先检查顶部工作模式。在线模式使用你配置的真实服务；离线演示使用本地合成样本。两种模式都不会在启动时自动下载或修改音乐文件。

## 配置服务

1. 在设置中选择自己的音乐目录，并检查临时、备份、隔离目录。目录必须互不重叠，应用拒绝未经确认的符号链接和 Windows junction。
2. 添加网易云歌单 ID 或公开链接。刷新歌单后查看完整性警告；上游缺失信息和不可用曲目保持待复核。
3. PT 检索需要分别导入对应站点的 Cookie-Editor JSON 登录态。导入后执行登录预检；应用以站点域名隔离凭据。
4. qBittorrent、歌词接口和 AI 服务分别配置地址及凭据。私有歌词接口支持原始 Authorization 值；AI 服务支持 Responses 协议。公共音乐资料查询也可根据服务要求配置鉴权。

密钥输入框不会显示已经保存的明文值。凭据保存在本地 Windows 账户的 DPAPI 保护文件中，不写入可导出的配置 JSON。

## 在线检查

音乐目录的快速索引只读取文件属性、有限标签和伴随文件属性，不计算整首音频哈希，也不执行整库解码。因此索引结果可以用于寻找候选、比较歌单和人工复核，不能作为完整音频健康证明。

歌曲／专辑识别优先保留已有标签和来源证据，必要时查询 MusicBrainz、Discogs 或打开 AllMusic、Rate Your Music、Album of the Year、VGMdb 查询入口。先核对艺人、标题、发行版本、专辑和时长，再决定如何补充缺失字段。候选不会自动覆盖音乐文件。

歌词和封面候选分开检查内容结构与歌曲身份。来源版本、现场录音、混音或专辑不一致时保持待复核。

## 任务控制

任务中心显示运行、暂停、失败和待复核状态。关闭主窗口后后台可能继续执行；再次打开可附着到同一运行档案。暂停或取消操作会在可中断的检查点生效。

真实下载、令牌操作和音乐文件发布需要相应的服务能力、预检和可复核计划。界面中未开放的操作不能通过离线演示结果视为已经完成真实验收。
