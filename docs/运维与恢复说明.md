# 运行档案与恢复

每个运行档案包含配置、SQLite 状态、任务记录和 Windows DPAPI 凭据。使用 `--base` 选择档案时，GUI 和后台必须指向同一位置。

备份运行档案前应暂停任务并退出该档案的后台进程。保留完整档案目录，可用于同一 Windows 账户的状态恢复；DPAPI 密钥不能保证在另一账户或机器上解密，迁移后应重新导入凭据。

不要将运行档案、数据库、Cookie、鉴权文件和个人歌单快照提交到 Git。公开仓库中的配置示例只包含通用占位值。

发现音乐文件在扫描期间发生变化时，索引会重试一次；仍在变化的文件记录为忙碌，须稍后复查。快速在线索引不会产生完整解码验证结果。

事务日志保留准备、提交与回滚证据。回滚之前需检查当前目标和备份是否仍符合预期；不要手动改写事务数据库以绕过文件冲突。先在离线合成样本中验证计划，再进行真实文件操作的独立验收。

升级应用前备份当前档案，保留原运行包。公开源代码的测试记录只能说明测试覆盖的场景，不代替私人服务、真实音乐文件和 Roon 客户端的现场验收。
