安装前请确认

升级前请在 MusicOps“任务中心”点击“退出应用及后台”。有正在执行的任务时，请先等待完成，或取消对应任务后退出。

旧版没有此按钮时，请在确认任务已停止后，通过“活动监视器”结束 MusicOps 桌面程序与后台核心 musicops。安装器不会强制终止任务。

个人资料位于 ~/Library/Application Support/MusicOps/profile，本安装包不写入该目录，也不访问钥匙串。

当前安装包没有 Developer ID Installer 签名和 Apple 公证。确认来自官方 GitHub Release 并核对校验值后，按 macOS“隐私与安全性”提示打开；无需关闭系统安全功能。

卸载时将“应用程序”中的 MusicOps 移到废纸篓即可，个人资料会保留。
